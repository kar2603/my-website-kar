KẾT NỐI CLOUD GOOGLE APPS SCRIPT (24/7 TRÊN VERCEL)

Giúp Admin Panel chạy vĩnh viễn trên domain mà không cần mở máy tính bật localhost.

📝 3 Bước Thiết Lập Nhanh (Mất 1 phút):

  1. Mở file Google Sheet SePay của bác: 👉 Mở Sheet SePay ↗
  2. Trên menu bấm Tiện ích mở rộng $\rightarrow$ chọn Apps Script.
  3. Xóa hết code cũ, dán toàn bộ mã nguồn trong file google_apps_script.js (có sẵn trong thư mục D:\web\).
  4. Bấm nút xanh Triển khai (Deploy) $\rightarrow$ Tùy chọn triển khai mới $\rightarrow$ Chọn loại Ứng dụng web (Web app).
  5. Ở mục Ai có quyền truy cập (Who has access): Chọn Bất kỳ ai (Anyone) $\rightarrow$ Bấm Triển khai và copy URL web app dán vào ô dưới đây:
